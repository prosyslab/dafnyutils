# `stat` 수치 메타데이터 명세

이 벤치마크의 `stat`은 파일 시스템 모델에 저장된 아이노드 상태를 사용자가
지정한 형식으로 출력한다.

```text
stat [OPTION]... FILE...
```

## 지원 동작

- `-c FORMAT`, `--format=FORMAT`: 필수 출력 형식을 지정한다. 각 파일의 결과
  뒤에는 줄바꿈을 하나 붙인다. 여러 번 지정하면 마지막 형식을 사용한다.
- `-L`, `--dereference`: 마지막 심볼릭 링크가 가리키는 대상을 조회한다.
- 여러 파일은 명령행 순서대로 처리한다. 한 파일의 조회가 실패해도 나머지
  파일을 처리하고 최종 상태를 실패로 반환한다.
- `--help`, `--version`을 지원한다.

지원하는 형식 지시자는 다음과 같다.

- `%a`: 접근 권한의 8진수 표현
- `%b`: 할당된 512바이트 블록 수
- `%B`: 블록 수 지시자가 사용하는 단위인 `512`
- `%d`, `%D`: 장치 번호의 10진수와 16진수 표현
- `%f`: 파일 종류 비트를 포함한 원시 모드의 16진수 표현
- `%g`, `%u`: 숫자 그룹 식별자와 사용자 식별자
- `%h`: 하드 링크 수
- `%i`: 아이노드 번호
- `%o`: 선호 입출력 블록 크기
- `%s`: 바이트 단위 크기
- `%X`, `%Y`, `%Z`: 접근·수정·상태 변경 시각의 시대 초
- `%%`: 백분율 문자 하나
- 나열되지 않은 `%` 지시자는 물음표 `?` 하나를 출력한다. 형식 끝의 단독
  `%`는 백분율 문자 하나를 출력한다.

## 제외 동작

- 기본 출력 형식
- `-` 피연산자로 표준 입력 파일 기술자의 메타데이터 조회
- 사용자와 그룹의 이름 조회
- 폭, 정밀도, 형식 플래그
- 사람이 읽는 시각, 생성 시각, 파일 시스템 전용 지시자의 실제 값
